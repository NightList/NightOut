## User Interaction & Clarification
When you need a decision, confirmation, or missing information from the user, always invoke the `AskUserQuestion` tool. 
- Do not ask for missing requirements or choices in conversational chat prose.
- Present clear multiple-choice options (2-4 choices) with descriptions to let the user select an option efficiently.
- Provide a clear `question` and short `header` (max 12 characters) as required by the tool.
- If necessary, allow the built-in "Other" escape hatch for free-text input.
