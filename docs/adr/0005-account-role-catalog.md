# ADR 0005: ชั้นบัญชีอิงตาราง `roles` และมีแต่ Super Admin ที่แก้ชั้นของบัญชีที่มีอยู่แล้ว

- **สถานะ:** Accepted
- **วันที่:** 2026-10-05

## Context
บัญชีถือชั้นความสามารถได้ชั้นเดียวที่ `users.role` ซึ่งเป็น enum `CUSTOMER` / `MERCHANT` / `STAFF` / `ADMIN` หน้าเว็บกับหลังบ้านจึงไม่มีรายการชั้นให้ดึงชื่อไทย และเพิ่มชั้นใหม่ต้องแก้ enum อย่างเดียว วันนี้ Admin คนไหนก็เรียก `admin_set_user_role` ตั้งชั้นได้ทุกค่า รวมถึง `ADMIN` กันไว้แค่ห้ามลดสิทธิ์ตัวเอง

ชั้นบัญชีคนละเรื่องกับตำแหน่งในร้าน (`bar_staff`) และชื่อบนหน้าทีม (`team_members.roles`)

## Decision
- แหล่งความจริงของชั้นบัญชีคือตาราง `roles` บัญชีชี้ไปที่หนึ่งแถว (`users.role` มี FK ไป `roles.code` — ชั้นที่ไม่มีแถวตั้งให้บัญชีไม่ได้) ชุดปิดห้าชั้น: `CUSTOMER` ลูกค้า, `MERCHANT` ร้านค้า, `STAFF` พนักงานร้าน, `ADMIN` แอดมิน, `SUPER_ADMIN` ซูเปอร์แอดมิน พฤติกรรมของแต่ละชั้นยังอยู่ในโค้ด ตารางเก็บชื่อไทย ลำดับแสดง และ `can_enter_backoffice` ที่ประตูหลังบ้านทุกจุดอ่าน (`is_admin`, `admin_assert`, `AdminGuard`, storage policy)
- enum `user_role` ยังเป็นชนิดของคอลัมน์ `roles.code` / `users.role` — ไม่ต้องรื้อ view และฟังก์ชันที่ใช้ชนิดนี้อยู่ ชั้นใหม่ต้องเพิ่มทั้งค่า enum และแถวในตาราง
- Super Admin ทำได้ทุกอย่างที่ Admin ทำได้ รวมถึงเข้าหลังบ้านหลังผ่าน MFA และเป็นชั้นเดียวที่แก้ชั้นของบัญชีที่มีอยู่แล้วได้ ใช้เมื่อสร้างบัญชีผิด
- Admin สร้างบัญชีแล้วเลือกได้แค่ลูกค้า ร้านค้า พนักงาน Super Admin สร้างได้ครบห้าชั้น สมัครเองได้แค่ลูกค้า
- สมัครเป็นร้าน และยอมรับคำเชิญเข้าทีม ยังเปลี่ยนชั้นเองได้ตามเดิม และไม่ลดชั้นที่สูงกว่า
- แก้ชั้นแล้วชั้นใหม่เป็นลูกค้า แอดมิน หรือซูเปอร์แอดมิน ให้หลุดจากร้าน ถ้ายังเป็นร้านค้าหรือพนักงาน ความผูกกับร้านอยู่ ร้านไม่มีเจ้าของได้ ซึ่งมีอยู่แล้ว
- ห้ามเหลือ Super Admin เป็นศูนย์ ลดชั้นตัวเองได้เฉพาะเมื่อยังมี Super Admin คนอื่น คนแรกถูกตั้งด้วยสคริปต์สร้างบัญชี ไม่ยก Admin ที่มีอยู่ทั้งก้อน
- หน้าเว็บลูกค้าได้รหัสกับชื่อไทยของบัญชีตัวเอง เปลี่ยนชั้นตัวเองไม่ได้ ปุ่มแก้ชั้นในหลังบ้านมีเฉพาะ Super Admin ปุ่มสร้างโชว์เฉพาะชั้นที่คนนั้นเลือกได้

## Considered Options
- ให้ enum เป็นแหล่งความจริงต่อ — เพิ่มชั้นได้ แต่หน้าเว็บไม่มีแถวให้ดึงชื่อไทย และบัญชีไม่ได้ชี้ไปที่รายการชั้น
- เก็บสิทธิ์เป็นธงบนแถว เพิ่มชั้นได้โดยไม่แก้โค้ด — ลูกค้า ร้านค้า พนักงานคนละหน้าในแอป ธงครอบไม่หมด
- ให้ Admin แก้สามชั้นล่างได้ — ยังเป็นทางลัดกว้างกว่าจังหวะสร้างบัญชี สมัครร้าน และรับคำเชิญ
- ไม่มีปุ่มแก้ชั้นเลย — ตั้งแอดมินผิดตอนสร้างแล้วแก้ไม่ได้

## Consequences
- ตาราง `roles` สร้างใน migration `…005000200_roles` · `SUPER_ADMIN` + กติกาอยู่ใน `…006000400_super_admin_enum` (ค่า enum แยกไฟล์ เพราะใช้ในธุรกรรมเดียวกับที่เพิ่มไม่ได้) และ `…006000500_super_admin_rules`
- `PATCH /admin/users/:id/role` ใช้ต่อ แต่ต้องเป็น Super Admin (`SuperAdminGuard` + `super_admin_assert` ใน DB) และปลดร้านตามกติกาด้านบน · `POST /admin/users` เช็กชั้นที่ผู้เรียกสร้างได้ก่อนสร้างบัญชี
- `GET /admin/roles` ตอบห้าชั้นพร้อม `can_create` / `can_assign` ของผู้เรียก · `GET /me/profile` เพิ่ม `role_label` กับ `can_enter_backoffice`
- `CANNOT_DEMOTE_SELF` เลิกใช้ แทนด้วย `LAST_SUPER_ADMIN` (ลบบัญชีตัวเองก็ตรวจ) และ `SUPER_ADMIN_REQUIRED`
- นำสมาชิกออกจากทีมร้านไม่ลดชั้นบัญชี ตามพฤติกรรมเดิม
